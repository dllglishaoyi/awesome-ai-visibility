# AI 可见度 / GEO 资源清单（中文）

英文版见 [README.md](README.md)。这里收集"品牌有没有被 ChatGPT、Claude、Gemini、Perplexity、Google AI 概览提到或推荐"相关的工具、免费检测、研究与公开数据。由 [GeoBuddy](https://geobuddy.co) 团队维护，竞品平等列出，只写事实，不排名。

## 免费检测（不用注册）

- [GeoBuddy 免费检测](https://geobuddy.co/check)：开着联网搜索，向 ChatGPT、Claude、Gemini、Perplexity 提你品类的问题，返回是否被提及、排第几、AI 推荐了谁。每天 3 次。
- [Ahrefs AI Visibility Checker](https://ahrefs.com/ai-visibility-checker)：基于 Brand Radar，覆盖 ChatGPT、Gemini、Copilot、Perplexity、AI 概览。
- [Semrush AI Search Visibility Checker](https://www.semrush.com/ai-visibility/)：ChatGPT、Gemini、AI 概览的免费一览。
- [HubSpot AEO Grader](https://www.hubspot.com/aeo-grader)：ChatGPT、Perplexity、Gemini 的综合评分。

## 监控平台

- [GeoBuddy](https://geobuddy.co)：4 个引擎，提及、排名、"推荐 vs 替代品"、竞品对比。Pro 每月 $49，Business 每月 $149，一次性 $299 修复包支持支付宝。每周公开[自测结果](https://geobuddy.co/methodology/self-test)。

- [AthenaHQ](https://www.athenahq.ai/)：YC 背景，统一 GEO 评分加内容 agent。

## 研究

- [GEO 原始论文（Aggarwal 等，KDD 2024）](https://arxiv.org/abs/2311.09735)：命名了这个领域，引用、统计数字、引语可带来约 40% 的可见度提升。
- [GeoBuddy 方法论](https://geobuddy.co/methodology)：评分怎么算，为什么引擎空回答算测量失败而不是 0 分。

## 三个测量陷阱

1. 引擎关掉联网搜索时，小品牌得分必然是 0：不是 AI 不喜欢你，是它根本不知道你。
2. 引擎宕机看起来和"0% 可见度"一模一样，空回答必须算失败而不是 0。
3. 曝光和点击是过程指标，只有真人回复和付费才算信号。
